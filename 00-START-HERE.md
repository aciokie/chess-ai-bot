## 🔍 Monitoring Commands

Use these in browser console (F12) to monitor:

```javascript
// Check engine status
console.log(state.engineStatus)
// Output: "loading", "ready", or "error"

// View all errors
window.__SF_ErrorReporter.dump()
// Shows all captured errors in table format

// Check download progress
console.log(state.wasmDownloadState)
// Shows: bytes, percentage, retry count

// Verify cache
await Cache.get('sf18_05_wasm').then(c => 
    console.log(`Cache: ${c ? 'HIT' : 'MISS'} (${c?.length || 0} bytes)`)
)

// Monitor in real-time
setInterval(() => {
    const s = state.wasmDownloadState;
    const pct = s.totalBytes ? Math.round(s.bytesReceived/s.totalBytes*100) : 0;
    console.log(`Download: ${pct}% (${s.bytesReceived}/${s.totalBytes})`);
}, 1000)

// Force cache clear
await Cache.delete('sf18_05_wasm')
// Next load will re-download
```

